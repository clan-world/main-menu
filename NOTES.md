# Console feel

- A generated full-screen illuminated parchment atlas and brass corner fittings make the browser feel like a game surface.
- Generated bronze plaques have illustrated relic icons, engraved root ornaments, separate idle/hover/pressed art and a dominant gold Play now button.
- The generated sanctuary plate drifts in a 10-second loop with rising generated crystal sprites and a floating relic marker. Ink whispers appear, linger and fade in a loop.
- Generated ivory-arrow and bronze-gauntlet cursors, optional synthesized menu tones, arrow-key navigation and focus-trapped overlays reinforce the console interaction.
- Mobile preserves large controls and places the living sanctuary above the stack. Motion can be disabled, including through the system preference.
- Three small playable interactions make the first pass tangible: awaken runes, reveal a pack, and solve the rune trial. No wallet or account flow.

Built with Vite + React. Run `npm install && npm run dev`. Desktop/mobile Playwright checks and production build pass.

The art pass uses the built-in image-generation tool throughout. No Imagine/video tool was available. Exact prompts and export details: [public/art/ART.md](public/art/ART.md).
