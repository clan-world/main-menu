# Console feel

- A full-screen illuminated atlas, dark perimeter and brass corner fittings make the browser feel like a game surface.
- Heavy, textured, inset-bordered controls have custom icons, diamond fittings, press feedback and a dominant gold Play now button.
- The right side lives through portal glow, rising embers, subtle scene breathing and a floating sanctuary marker. Ink whispers appear, linger and fade in a loop.
- Custom parchment/sword cursors, optional synthesized menu tones, arrow-key navigation and focus-trapped overlays reinforce the console interaction.
- Mobile preserves large controls and places the living sanctuary above the stack. Motion can be disabled, including through the system preference.
- Three small playable interactions make the first pass tangible: awaken runes, reveal a pack, and solve the rune trial. No wallet or account flow.

Built with Vite + React. Run `npm install && npm run dev`. Desktop/mobile Playwright checks and production build pass.
