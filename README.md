## Criteria

- Feels like a **console game** main menu in the browser (Cambria.gg direction + Clan World parchment/runes).
- Avoid “divs with basic styling.” Textured, ornamented buttons. Custom cursors. Immersive chrome.
- Mobile + desktop.
